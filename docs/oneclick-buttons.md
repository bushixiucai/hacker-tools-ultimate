## 网站奇遇（`site`）
- **一键给官网飘满弹幕**　日志：装填弹幕 ×999… / 发射「前方高能」… / 覆盖整页 99%　反转：弹幕只飘在你自己屏幕上，内容全是「作者好帅」。
- **一键让后台自己交出密码**　日志：发送求饶包… / 管理员正在犹豫… / 获取密码 99%　反转：后台回复：「密码是：好好学习」。说完它就下线了。
- **一键把官网换成猫片**　日志：上传 3000 张橘猫… / 替换首页横幅… / 生效 99%　反转：只换了你自己浏览器里的这一页。世界依旧，猫依旧可爱。

## 人生破解（`crack`）

- **一键破解周一**　日志：分析周一加密算法… / 绕过闹钟守护进程… / 解密 99%　反转：破解失败：周一的密钥由你的闹钟保管，它不肯给。
- **一键把需求文档反编译成人话**　日志：载入 PRD v9.9.9… / 剥离「对齐」「抓手」「赋能」… / 输出 99%　反转：反编译结果只有一句：「先做个能用的。」
