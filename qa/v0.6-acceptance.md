# v0.6 acceptance record

Date: 2026-10-18

## Scope

All twelve independent tools, twenty quick actions, isolated runtime contracts, public website metadata preparation, report PNG export and fragment replay are implemented against PRD v0.6. Original Matrix styling, header navigation, home cards and desktop terminal split are retained. Mobile uses the action area before the terminal.

## Automated acceptance

- Source network boundaries, naming and archived script schema checks pass.
- TypeScript and production Vite build pass.
- 10 core tests cover registry discovery, normalization, input validation, atomic starts, isolated state, waiting choices, cancellation, graceful stop and bounded history/logs/events.
- 33 Chromium browser tests cover the twelve tools, public metadata/denial/timeout, editing and restoring CMS content, media loading, causal branches, touch controls, scoped shell commands, lifecycle cleanup, disclosures, PNG output and network-free replay.
- 2 quick-action tests cover all twenty actions, unique conclusions, required inputs, cancellation and narrow-screen dialogs.
- 7 iPhone WebKit tests cover website/CMS, camera video readiness, typing and phone state, 320/390/landscape layouts and PNG/replay.

Commands: `cd app && npm run test:e2e && npx playwright test -c playwright.mobile.config.ts`.

Local visual evidence is saved under ignored `output/playwright/`. Browser emulation does not constitute a physical iPhone test. Camera video is locally bundled fictional footage with H.264 support; metadata remains subject to target CORS and silently uses the generated scenario when unavailable.

## Release gate

GitHub Actions runs the same production build, core/browser/quick-action tests and iPhone WebKit checks before uploading that exact build to Pages. Deployment completion and public artifact verification are recorded in the delivery response and the repository Actions deployment history.
