# v0.7 自动推进与过程文案验收

日期：2026-10-19。依据用户选择“1A 输入一次其余自动、2C 过程张狂结尾疯狂”，过程文案同样纳入调整。原 Matrix 风格、页面结构、移动端策略和网络边界保留。

## 默认交互

| 范围 | 默认路径 |
|---|---|
| 网站 | 网址→自动受限改路/会话建立→自动打开CMS |
| 扫描/密码 | 目标→自动扫描/候选扩展与冷却→报告 |
| 摄像头 | 目标→自动发现和接入4路→自由控制 |
| 定位 | 目标→自动筛选信号/3次采样→街区 |
| 警报 | 启动→倒计时→手动或自动解除与反转 |
| DDoS/大屏 | 目标→直接进入持续运行画面，可自由调整或停止 |
| WiFi | 网络名→自动接入点/追频/补帧/候选扩展→成果 |
| 打字机 | 启动→直接自由输入，无需场景选择 |
| 手机 | 目标→自动身份与链路协商→主屏与日常应用 |
| 钱包 | 地址→自动识别NVA/AST/扩大索引→资产和交易 |
| 20快捷 | 最少输入后启动，无目标项点击即跑→自动结论→短反转 |

全部非目标参数初始折叠，不展开也能运行。自由编辑、云台、手机应用、调参、筛选、地图层级等保留；它们不再作为必过关卡。非法输入与主动覆盖的错误参数仍校验。

## 文案层次

- 过程覆盖卡片说明、按钮、阶段、终端输出、等待、自动重试与结果。例如“正门有锁？换条路”“三路信号对齐，坐标钉死”一类技术电影口吻，协议与数值继续自洽。
- 每工具独立结尾：网站宇宙主编、端口赛博户口本、密码词典摇号、镜头总导演、定位火星交通台等。
- 20快捷同样有各自过程旁白和荒诞反转，而非统一替换一个标题。
- 自然业务内容和校验错误仍保持可读、准确；模拟说明独立保留，结尾明确没有真实操作。

## 验证

- 核心测试明确禁止内置definition调用阻塞式 `ctx.choose`，并逐一执行12默认流程抵达各自可用状态。
- 保留扩展选择API、取消、独立状态、日志容量和清理等核心回归；另验双链地址自动识别。
- 浏览器继续检查12工具实际控件、输入校验、自动流程、跨工具返回、媒体清理、回放无网络与原布局。
- CMS后台完成不会抢其他工具；返回时自动打开，关闭结束后不会反复打开。
- 快捷逐项核对不同证据、自动结论/反转和取消计时器；无深度或查看结论的必要点击。
- 移动端验证全部参数默认折叠，以及320/390/横屏、WebKit、44px控件、16px编辑和本地媒体。
- 机械界面检测对本轮变更的main和专属视图无新增发现。
- 验收门禁包含14项核心、40项Chromium、2项快捷操作和12项有效WebKit检查；iPhone不支持的元素全屏用例单独跳过。
- GitHub Actions重跑完整门禁后部署同一份产物，线上核对哈希并实测默认路径；实际发布记录见交付链接。

移动端证据来自仿真浏览器，未进行实体手机验收。历史v0.6评审保留作为当时记录，不再作为人工选择流程的现行标准。
